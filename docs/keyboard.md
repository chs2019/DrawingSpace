# Keyboard and pointer reference

| Input | Action |
| --- | --- |
| Ctrl+1 | Pointer Tool |
| Ctrl+2 | Text Tool |
| Ctrl+3 | Connector Tool |
| Ctrl+S / O / N | Save / Open / New blank drawing |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+Shift+Z | Redo |
| Ctrl+C / X / V | Copy / Cut / Paste |
| Ctrl+D | Duplicate |
| Ctrl+A | Select all visible objects |
| Ctrl+G | Group selected shapes |
| Ctrl+Shift+G or Ctrl+Shift+U | Ungroup |
| Ctrl+B / Ctrl+I | Toggle bold / italic |
| Ctrl+F | Find a shape by name, label or data |
| Delete / Backspace | Delete selection |
| F2 | Edit selected object's label |
| Arrow keys / Shift+arrow | Move selection by 1 / 10 drawing pixels |
| Escape | Cancel gesture, leave current tool, clear selection |
| Space+drag or middle drag | Pan |
| Ctrl+wheel | Zoom around the pointer |
| Wheel / Shift+wheel | Vertical / horizontal pan |
| Double-click shape or connector | Edit label |
| Enter while editing label | Commit label |
| Shift+Enter while editing label | New line |
| Escape while editing label | Cancel label edit |
| Shift+click | Toggle selection membership |
| Left-to-right marquee | Select enclosed shapes |
| Right-to-left marquee | Select intersecting shapes |
| Shift+resize | Preserve aspect ratio |
| Shift+rotate | Snap rotation to 15-degree increments |
| Alt+drag | Bypass grid and dynamic snapping |
| Click blue AutoConnect arrow | Add a connected copy of the selected shape |
| Double-click page tab | Rename page |

Commands do not intercept normal text entry inside a text field. Browser and OS reserved shortcuts can differ; use the ribbon commands when a browser reserves a key combination. Windows-key/Command modifier states are also recognized by the native keyboard path, but cross-platform shortcut parity is not yet exhaustively tested.
